## 🎯 Sobre este repositório

Este é o repositório de **backend** do teste técnico. Aqui deve entrar a API construída para
alimentar a tela **Resumo Financeiro**, cujo frontend já está pronto (hoje rodando com dados
mockados) no repositório irmão:

🔗 **Frontend:** [github.com/MTW-TECH/Teste-Resumo-Financeiro](https://github.com/MTW-TECH/Teste-Resumo-Financeiro)

## 🧩 O que esperamos aqui

- [ ] Uma **API REST** que consulte o banco **PostgreSQL** de desenvolvimento fornecido
- [ ] Endpoints que alimentem os dados hoje mockados na tela: dados da empresa e os
      indicadores de Receita, Custos, Taxas, Lucro Líquido e EBITDA, além da evolução mensal e
      do detalhamento de custos
- [ ] Projeto **containerizado com Docker**, pronto para subir com poucos comandos
- [ ] Um README próprio explicando como rodar o que você construiu aqui
